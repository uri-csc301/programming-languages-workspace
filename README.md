# CSC 301 – Fundamentals Of Programming Languages

Welcome to CSC 301! This repository serves as your primary workspace for the course. Throughout the semester, you will use this repository to:
- Review lecture examples  
- Practice with self-assessment problems  
- Complete and submit assignments  

---

## About The Course

In this course, we explore the fundamental concepts of programming languages including:
- Programming paradigms (functional, object-oriented, logic)
- Language design and implementation
- Syntax and semantics
- How different languages approach problem-solving

By the end of the course, you should be able to:
- Compare major programming paradigms  
- Choose appropriate languages for different problems  
- Learn new programming languages more effectively  

---

## Languages & Tools

In this course, you will work with:
- **Standard ML (SML)**
- **Java**
- **Prolog**

We will use **GitHub Codespaces** as our development environment. This allows you to:
- Code directly in your browser (no installation required)
- Work in a consistent environment across all languages
- Easily manage and submit your work

Throughout the semester, you are expected to **make regular contributions** to your repository as you complete problems and assignments in the appropriate folders.

## Getting Started

Follow these steps to create your own copy of the course repository:

1. Create a GitHub account (if you do not already have one)
2. Open the **<a href="https://github.com/uri-csc301/programming-languages-workspace">CSC301 Template repository</a>**  
   ⚠️ **Do NOT fork this repository**
3. Click **Use this template → Create a new repository**
4. Name your repository (e.g., `csc301-yourname`)
5. Set visibility to **Private**
6. Click **Create repository**

---

## Adding Teaching Staff To Your Repository

You must add teaching staff as collaborators so we can access your work.

1. In your repository, go to **Settings → Collaborators**
2. Click **Add people**
3. Add the instructor and TA information provided in the **Setting Up Your Workspace** page in our Brightspace course (**Content → Week 1**).

This ensures we can view your work while keeping it private from other students.

---

## Navigating Your Repository

After creating your repository from the template, you will see the following structure:

```
lecture-examples/     → Code demonstrated in lectures
self-assess-problems/ → Optional practice problems (not submitted)
assignments/          → Graded weekly assignments to be submitted
```

You will work inside this repository throughout the semester.

---

## Using Codespaces

Follow these steps to open your repository in Codespaces:

1. Go to **your repository** (not the template repo)
2. Click **Code → Codespaces → Create Codespace**
3. Wait for the environment to load

Once loaded, you can begin coding directly in your browser.

## Getting Familiar With The Workflow

To practice using Codespaces:

1. Open Codespaces using the steps above  
2. Navigate to:

```
lecture-examples/week-01-recursion/
```

3. Open and follow the instructions in:
```
pl-instructions.md
```

This will walk you through running example programs from the lecture.

4. Then move to:

```
self-assess-problems/week-01-recursion/
```

5. Open and follow the instructions in:
```
recursion-instructions.md
```

and try the practice problems.

6. Then move to:

```
assignments/week-01-recursion/
```

7. Open and follow the instructions in:
```
a1-instructions.md
```

and complete the assignment.

This process reflects how you will complete work throughout the semester.

## Saving & Submitting Your Work

You are expected to **commit your work regularly**.

### Option 1: Using the Terminal

```bash
git add .
git commit -m "Your descriptive message"
git push
```

---

### Option 2: Using the Source Control Panel

1. Click the **Source Control** icon
2. Enter a message describing your changes
3. Click **Commit**
4. Click **Push**

You can also use **Commit & Push** (dropdown arrow button) and additional actions via the **... menu**.

---

## Submitting Assignments

When submitting assignments:

- Make sure your work is **committed and pushed**
- Submit a **link to your private repository** on Brightspace
- Ensure teaching staff have access to your repository

## ⚠️ Academic Integrity

All work in this course must be **your own**.

You may NOT:
- Copy code from other students
- Use solutions from the Internet or repositories
- Use AI tools (e.g., ChatGPT, Copilot) unless explicitly allowed

If your work is flagged, you may be asked to:
- Explain your code
- Review your commit history
- Provide supporting materials (drafts, notes, etc.)

Refer to the **Academic Honesty page** in our Brightspace course (**Content → Getting Started**) for full details.
